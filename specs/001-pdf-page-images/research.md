# Phase 0 Research: Конвертация PDF в изображения страниц

## Decision 1: Серверный формат сервиса

- Decision: HTTP-сервис с одним синхронным endpoint для конвертации одного PDF за запрос.
- Rationale: Соответствует уточнению по серверной обработке и JSON-ответу; проще запуск и тестирование на MVP.
- Alternatives considered:
  - Асинхронные job-очереди: лучше для тяжелых задач, но избыточно для MVP.
  - CLI-only утилита: не подходит под требование возвращать результат в ответе на запрос.

## Decision 2: Движок рендеринга PDF

- Decision: Использовать движок рендеринга страниц PDF с явной настройкой DPI (целевое значение 300).
- Rationale: Требование читаемости чертежей и тонких линий требует стабильного рендеринга и контроля DPI.
- Alternatives considered:
  - Низкий DPI (150-200): быстрее, но ухудшает читаемость.
  - Векторный вывод без растра: не соответствует требованию вернуть изображения страниц.

## Decision 3: Формат ответа

- Decision: Возвращать JSON с массивом страниц, где каждая страница содержит метаданные и содержимое изображения.
- Rationale: Утверждено в clarify; удобно для прямой интеграции клиентом.
- Alternatives considered:
  - ZIP-файл: эффективнее по размеру, но против выбранного бизнес-требования.
  - Ссылки на временные файлы: добавляют жизненный цикл хранения и очистки.

## Decision 4: Политика ошибок

- Decision: Возвращать детализированные бизнес-ошибки для невалидного PDF, password-protected PDF и отсутствующего входного файла.
- Rationale: Уменьшает время диагностики; согласовано в спецификации.
- Alternatives considered:
  - Единая общая ошибка: проще, но ухудшает UX и тестируемость сценариев.

## E2E Validation Note

- Decision: Провести smoke-проверку endpoint через `fastapi.testclient`.
- Rationale: Быстро подтверждает работоспособность основного сценария без поднятия отдельного окружения.
- Alternatives considered:
  - Ручной прогон через `curl`: дольше и хуже автоматизируется.
- Result:
  - `POST /v1/convert` с одноcтраничным PDF, сгенерированным через Pillow.
  - HTTP `200`, `status=success`, `page_count=1`, `request_id` присутствует.
